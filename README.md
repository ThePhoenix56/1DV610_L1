# Laboration 1 – Fortsätt programmera

Simpelt program skrivet i JS (Node) som efterfrågar en användares namn för att sedan kolla vilken tid på dygnet det är och sist returnera ett meddelande beroende på tiden på dygnet.

## Kom igång

För att köra igång programmet, öppna en kommandkonsol/git bash i rätt katalog (directory) och kör **node main.js**.
